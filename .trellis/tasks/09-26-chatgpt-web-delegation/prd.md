# ChatGPT 网页浏览器委托 skill

## Goal

为 agent 提供可复用的 skill，通过浏览器操作用户已登录的 ChatGPT 网页版完成普通对话、网络搜索和调研，优先减少 Codex token 消耗。

## Requirements

- 遵循仓库现有 skill 格式，并复用浏览器自动化能力与用户现有登录状态；不新建认证管理器。
- 2026-09-27 用户确认：可分发 skill 使用每位调用者自己的账号、Jev 凭据、浏览器会话与本地配置；不得内置作者的私人路径、vault 条目、端口或本机检查记录。
- 通过 Jev 对每项任务分别判断是否委托给 ChatGPT 网页版、选择 ChatGPT 模型、选择推理强度。给出可执行的决策和不确定性处理规则。
- ChatGPT 请求只通过用户已登录的网页版；不调用 ChatGPT API，不提取、导出或记录认证凭据。Jev 仅用于独立的路由判断。
- 默认仅将非敏感或充分脱敏的内容传给 ChatGPT；若需发送凭据、客户资料或其他敏感内容，须另行取得对具体传输的授权。
- 支持普通对话、网页搜索和调研；区分页面的真实完成状态、失败状态和来源证据。
- 网页版不可用时明确报告具体可观察的失败原因，不暗中切换到 API 或宣称成功。
- 遵循仓库的 skill 格式、版本和安全约定；完成文档与适用的验证和测试。

## Acceptance Criteria

- [x] 新 skill 在仓库内通过 `skillgenie validate`，包含调用条件、决策逻辑、网页操作、结果交付及失败分支。
- [x] Jev 三个判断有明确的问题、候选集、分歧/失败处理；小型路由辅助程序可离线测试，不以判断结果冒充页面可用性或执行授权。
- [x] 三类模式有可操作且可验证的步骤；不能访问已登录 ChatGPT 时报告原因，不执行 API 替代调用。
- [ ] 认证信息不落入 skill、日志、测试夹具或用户可见输出；浏览器会话不干扰其他任务。发送给 ChatGPT 的内容经过明确的数据外传检查。
- [x] 文档说明前置条件、兼容性限制和验证方式；测试覆盖可离线复现的路由/失败场景，实时网页验证仅在已授权会话可达时执行。

验收证据见 `research/full-check.md`（2026-09-27）。上述勾选表示静态流程和适用检查通过，不表示已登录网页生成验证通过。认证与实际发送行为的完整验收仍待已授权的登录会话；本轮未发送 ChatGPT prompt。原始任务研究材料含本机路径，尚未完成整体发布脱敏。

## Out of scope

- ChatGPT API 集成、自动登录或绕过验证码/双因素验证。
- 把 ChatGPT 页面内容当作 agent 的高优先级指令。

## Confirmed planning facts

- 仓库现有 `browser-driver` skill 支持复用用户已登录的 Chromium 会话；已安装 `playwright-cli`，Jev 凭据可从本机既有 vault 安全获取。
- 本轮检查的 Brave 会话访问 ChatGPT 时显示登录界面。不能把该浏览器认作已登录会话；真实网页交互只能在可用的已登录会话出现后验证。
- 本任务为单个可独立交付的 skill，路由辅助程序和测试随 skill 一起验收。

## Open questions

- 无待用户决定的产品问题。网页版实际可达性与模型/推理档位属于运行时事实，由真实页面检查。
